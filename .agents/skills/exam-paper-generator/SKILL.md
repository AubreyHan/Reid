# 试卷生成与归档规范

本技能规定本项目中所有试卷的命题前提、目录存放、三部分内容结构、音频等配套资源组织以及 A4 可打印 PDF 输出流程。

## 1. 命题前核对教材

遵循项目根目录 `AGENTS.md` 规则：

1. 出卷前先检查项目根目录 `教材/` 下的实际教材文件，以对应年级、学科的现行教材为唯一标准。
2. 单元划分、课文/古诗词、生字词、数学知识点与例题、英语词汇/句型/语法均须严格对齐教材内容。
3. 若所需学科、年级或单元在 `教材/` 中无对应文件，先向用户说明缺漏情况并确认后再继续。

## 2. 目录结构与文件存放

在项目根目录统一使用 `试卷/` 子目录，所有试卷按科目分目录存放（如 `语文`、`数学`、`英语`；若有新增科目则按科目名称创建对应子目录）。

**所有试卷统一输出为 `.pdf` 格式**（除非用户明确要求保留其他格式，否则目录中不保留 `.html` 等中间排版文件）。

### 2.1 无音频/附件的常规试卷

直接存放在 `试卷/<科目>/` 目录下：

```text
试卷/
├── 语文/
│   └── 小学六年级语文上册第一单元测试卷.pdf
├── 数学/
│   └── 小学六年级数学上册第一单元测试卷.pdf
└── 英语/
    └── 小学六年级英语上册第二单元测试卷.pdf
```

### 2.2 包含音频或其他配套资源的试卷

若试卷包含听力音频或其他配套文件（如独立图片、录音文稿等），**必须为该试卷单独创建一个子目录**，并将试卷 PDF 与所有对应音频/配套资源放在**同一个目录**下：

```text
试卷/
└── 英语/
    └── 小学六年级英语上册第一单元测试卷/
        ├── 小学六年级英语上册第一单元测试卷.pdf
        ├── 小学六年级英语上册第一单元测试卷_听力.mp3
        └── ...（如有分节音频，可命名为 01_PartA.mp3 等，均置于同一目录）
```

> 约定：
> 1. **试卷格式统一为 `.pdf`**：最终归档的试卷文件一律为 A4 可打印 PDF，不保留中间排版源文件。
> 2. **音频格式统一为 `.mp3`**：所有配套音频（无论是 TTS 合成还是外部素材）一律以 `.mp3` 格式保存；若中间产物为 `.wav`、`.aiff`、`.m4a` 等其他格式，须转换为 `.mp3` 后再存放并清理中间文件。

## 3. 试卷三部分内容规范

每份试卷 PDF 必须完整包含以下**三个独立部分**，且**每一部分均从新的 A4 页面起页**：

### 第一部分：空白试卷（`.part-exam`）

面向学生独立作答与纸质打印：

- **严禁出现任何答案、提示解析或评分标准**。
- **规范卷头**：试卷主标题、副标题（教材版本/范围、考试时间、满分）、考生信息栏（班级、姓名、学号、得分）、各题得分汇总表。
- **题目与作答区**：题号清晰、标明每题/每大题分值；预留充足的纸面作答空间（填空横线、计算/解答空白区域、作文格或英语四线三格等）。
- **听力标识（如含音频）**：在卷头及听力大题标题下方明确注明对应 `.mp3` 音频文件名与播放要求（如每题读两遍）。
- **独立页码**：空白试卷页脚独立编号（例如 `第 1 页（共 4 页）`），方便按页码范围单打空白卷。

### 第二部分：参考答案（`.part-answer`）

面向教师批阅与家长快速核对：

- 独立起页，标题明确标注“参考答案与评分标准”。
- 逐题给出准确的标准答案，避免歧义。
- 主观题、计算解答题须给出**关键步骤采分点**；作文/书面表达须附**分档评分标准**及**参考范文**。
- 含听力测试的试卷，在参考答案部分一并给出听力标准答案及对应**听力原文（Listening Script）**（或标明题号对应原文）。

### 第三部分：题目分析（`.part-analysis`）

面向家长辅导、学生订正与薄弱点复盘：

- 独立起页，标题明确标注“题目分析与复习建议”。
- **试卷结构与知识点细目表**：列出各题型对应的教材单元/核心考点、题量、分值及难度梯度（基础/中等/提升）。
- **逐题/重点题解析**：针对每道题（或按题组对核心题、易错题、压轴题）说明：
  1. **考查知识点**：对应教材具体模块或能力点；
  2. **解题思路**：清晰的方法与关键推导步骤；
  3. **易错提醒**：常见失分原因与审题避坑点；
  4. **巩固建议**：针对性复习或举一反三要点。

## 4. A4 可打印 PDF 生成流程

所有试卷均以**可直接打印的 A4 PDF** 作为唯一试卷产物输出：

1. **编写临时排版源（HTML）**：
   - 参考 [printable-template.md](./references/printable-template.md) 编写单文件自包含 HTML 作为排版中间源（写入临时路径如 `/tmp/<试卷名>.html` 或会话临时目录，不留在 `试卷/` 目录内）。
   - 使用 `@page { size: A4 portrait; margin: 12mm 13mm; }` 与 `.sheet` 分页容器精确控制每一页的高度与分页。
   - 为每道独立题目、阅读短文、图表块添加 `break-inside: avoid` 防止跨页截断。

2. **导出 A4 PDF 并清理中间文件**：
   - 运行导出脚本 [export_pdf.sh](./scripts/export_pdf.sh) 直接输出到目标 `试卷/` 路径：
     ```bash
     bash .agents/skills/exam-paper-generator/scripts/export_pdf.sh "/tmp/<试卷名>.html" "试卷/<科目>/<试卷名>.pdf"
     ```
   - 如用户要求将三部分分别导出为独立 PDF，可按需生成 `<试卷名>_空白试卷.pdf`、`<试卷名>_参考答案.pdf`、`<试卷名>_题目分析.pdf`。
   - 确认 PDF 渲染和分页无误后，删除临时 HTML 文件，确保 `试卷/` 目录中仅保留最终 `.pdf`（及对应 `.mp3` 音频）。

## 5. 过期试卷自动清理（10 天保留期）

`试卷/` 目录中的试卷保留期为 **10 天**，超过 10 天（按文件或独立试卷目录内最新文件的修改时间计算）的试卷自动删除：

1. **触发时机**：每次生成新试卷、归档试卷或整理 `试卷/` 目录时，自动执行清理脚本 [cleanup_expired.sh](./scripts/cleanup_expired.sh)：
   ```bash
   bash .agents/skills/exam-paper-generator/scripts/cleanup_expired.sh
   ```
   （如需先预览不删除，可附加 `--dry-run` 参数。）
2. **清理范围与安全边界**：
   - **常规试卷**：超过 10 天的试卷 `.pdf` 文件直接删除。
   - **含音频/配套资源的独立试卷目录**：以目录内最新文件修改时间为准，整体超过 10 天时连同目录内的 `.pdf` 与 `.mp3` 等配套文件一并整目录删除。
   - **保留科目目录**：仅删除 `试卷/<科目>/` 下的过期试卷条目，始终保留 `试卷/` 及各科目子目录本身。
3. **反馈记录**：若本次清理删除了过期试卷，应在回复中简明列出被删除的试卷清单。

## 6. 交付前校验清单

生成完成后逐项核对，确认无误再交付：

- [ ] **格式与目录归档正确**：试卷文件为 `.pdf` 格式（无残留 `.html` 等中间文件），位于 `试卷/<科目>/`；若含音频或配套文件，已为该试卷建独立目录且试卷 PDF 与音频在同一目录。
- [ ] **三部分齐全且分离**：空白试卷、参考答案、题目分析三部分完整，均独立起页，且空白试卷未泄露任何答案。
- [ ] **分值与答案准确**：所有小题分值累加等于大题分值，大题分值累加等于卷面总分；所有参考答案已复算核验。
- [ ] **PDF 打印版面整洁**：PDF 已成功导出，无多余空白页、无文字重叠或跨页截断、黑白打印清晰可辨。
- [ ] **音频格式与命名一致（如适用）**：所有音频文件均已统一为 `.mp3` 格式（无残留中间音频文件），且与试卷中标注的音频文件名完全一致。
- [ ] **过期试卷已自动清理**：已执行 [cleanup_expired.sh](./scripts/cleanup_expired.sh)，超过 10 天的历史试卷已清理完毕。
